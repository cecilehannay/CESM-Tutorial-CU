## Purpose

The Community Earth System Model (CESM) version 2 is a state-of-the-art global Earth system
model used for prediction and understanding of a wide variety of aspects of the Earth system.
CESM2 is freely available for use by the climate research community, making it an ideal tool
for Earth system research and education. Read more about the CESM model
[here](https://www.cesm.ucar.edu/).

Designed for new CESM2 users, this tutorial provides hands-on experience running the model on the NSF NCAR Derecho supercomputer. It was developed for *Climate Modeling Laboratory*, a course offered at CU, and has been taught successfully since 2016. The tutorial consists of two 75-minute class sessions that introduce the basic steps for setting up and running CESM. Undergraduate and graduate students use the skills they learn to conduct a wide variety of projects for the course.

Although the materials were created for a CU course, instructors at other institutions can readily adapt them for their own classes.

Enjoy!

## By the end of this tutorial, you'll be able to...

* Describe the basic structure of CESM and navigate its five key directories: `code`, `inputdata`, `case`, `build/run`, and `archive`.
* Download the CESM code and run an out-of-the-box simulation.
* Change the length of a run and resubmit it to continue the simulation.
* Find and interpret output, log, and timing files, including what to check first when a run crashes.
* Modify a namelist (for example, to change the CO₂ concentration).
* Explain the differences among different types of runs (startup, branch, and hybrid runs) and set up each type.
* Find guidance on making source-code modifications.
* Find additional documentation, learning resources, and help when needed.
