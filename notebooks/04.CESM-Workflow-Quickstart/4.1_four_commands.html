The 4 commands to run CESM#

Running CESM involves four main steps:

  1. Create a case.

  2. Set up the case.

  3. Build the CESM executable.

  4. Submit the simulation.

You can run the most basic simulation with 4 commands:

Each command performs a different task. Understanding these steps will make it much easier to modify your simulations and diagnose problems later.

Step 1: Create the case#

Overview of the directories before create_newcase#

The figure below illustrates where the create_newcase command is located within the CESM directories:

The create_newcase command is located in the cime/scripts directory of the CESM code:

cd ~/code/release-cesm2.1.5/cime/scripts

Syntax of create_newcase#

The general form of the command is:

./create_newcase \
    --case ~/cases/CASENAME \
    --compset COMPSET \
    --res GRID

Important

CASENAME, COMPSET, and GRID are placeholders. Do not enter them literally. Replace them with the values selected for your experiment.

This command creates a new case directory containing the configuration for your experiment.

When you create a new case, you make three choices:

Choice

What it means

Case name

The name of your experiment

Component set (COMPSET)

Which model components and experimental conditions CESM will use

Grid (GRID)

The horizontal resolution used by the model components

Overview of the directories after create_newcase#

The figure below illustrates the directories after running create_newcase:

At this stage, CESM knows where the case, build/run, and archive directories will be located

The model has not yet been built or run.

Step 2: Set up the case#

case.setup prepares the scripts and configuration files that CESM needs to build and run the experiment.

To setup your case, move into the case directory:

cd ~/cases/CASENAME

Then run:

./case.setup

Overview of the directories after case.setup#

The figure below illustrates the directories after running case.setup:

At this stage, the model has still not been compiled or run.

Step 3: Build CESM#

Overview of the directories after case.build#

Build the model executable with:

qcmd -- ./case.build

Building means compiling the CESM source code into an executable program that Derecho can run. The qcmd command asks Derecho to perform the build on a compute node. Building CESM is computationally intensive and should not be done directly on a login node.

The figure below illustrates the directories after the case.build command:

A successful build produces the CESM executable in the build directory. The model is now compiled, but it has not yet been run.

Note

You normally build a case only once. You may need to rebuild it later if you change the source code or certain configuration settings.

Step 4: Submit the simulation#

Submit the simulation with:

./case.submit

This command sends the simulation to Derecho’s PBS batch scheduler.

Overview of the directories after case.submit#

The figure below illustrates the directories after the case.submit command:

The model does not necessarily begin running immediately. It may wait in the queue until the requested computing resources become available.

When the job starts, CESM runs in the run directory.
